## What is BGRemover?

BGRemover removes the background from product photos and artwork in batch, with transparent PNG output.

- **Free trial** — 10 successful files before a licence is required
- **Monthly licence** — one active device at a time
- Batch processing with engines that run locally and online
- Your source files stay on your own computer

## Auto-update

Once installed, BGRemover checks this repository for new releases on startup. If a newer version is published here, the app downloads it in the background and prompts you to restart when it is ready.
